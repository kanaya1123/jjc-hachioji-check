JELLY JELLY CAFE 八王子店 iPad専用 店舗チェック

Firebase・ログインなしの1台運用版です。

機能:
- iPad内にチェック状態を保存
- 日付が変わると新しい日の状態へ自動切替
- 前日に作成した「時間がない時は翌朝へ」の未完了項目を翌日に持ち越し表示
- 「今日ビールを使用した」でビール締め作業を表示
- 火曜・日曜にゴミ出しを表示
- 22時前はレジ締めをチェックできない
- 進捗表示
- PWA対応（HTTPS公開後、Safariの「ホーム画面に追加」でアプリ風に起動）

注意:
index.htmlをダブルクリックしたローカル状態では、PWAのホーム画面追加やService Workerは使えません。
実際の店舗運用ではHTTPSで公開します。
